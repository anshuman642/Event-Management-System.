# EventEase - Event Management System

EventEase is a full-stack event management system designed to simplify event creation, registration, management, and communication.

## Features

- User registration and login
- JWT-based authentication
- Create and manage events
- Event registration
- User and event management
- Responsive frontend
- REST API based backend
- Email integration
- Secure environment configuration

## Tech Stack

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API
- JWT Authentication

### Database
- MongoDB

## Project Structure

```text
EventEase/

```

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```

## Environment Variables

Create a `.env` file inside the backend folder and add your required environment variables.

Do not upload `.env` to GitHub.
